## SQL vs NoSQL

| Feature | SQL | NoSQL |
|---------|-----|-------|
| Schema | Fixed | Flexible |
| Scaling | Vertical | Horizontal |
| Transactions | Strong ACID | Eventual consistency |
| Query | SQL | Varies |
| Examples | PostgreSQL, MySQL | MongoDB, Redis, Cassandra |
